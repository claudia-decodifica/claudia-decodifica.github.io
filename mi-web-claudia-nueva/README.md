# Claudia Dueñas — Sitio web personal

Mi portafolio y espacio personal en la web: quién soy, qué hago y en qué estoy trabajando.

🔗 **Sitio:** https://claudia-decodifica.github.io

## Secciones

- **Sobre mí**: trayectoria en educación, gestión de pequeñas empresas y análisis de datos.
- **Servicios**: en qué puedo ayudar.
- **Blog**: ideas en proceso y notas de aprendizaje sobre datos y vida en común.
- **Contacto**: cómo escribirme.

## Tecnología

- HTML y CSS, sin frameworks.
- Publicado con GitHub Pages.

## Estructura del proyecto

```
├── index.html   # contenido de la página
├── style.css    # estilos
├── img/         # fotografías
└── README.md    # este archivo
```

## Cómo verlo en local

Abre `index.html` en el navegador. No necesita instalación.

## Formulario de contacto

El formulario envía los mensajes a [Formspree](https://formspree.io). Para activarlo, sustituye `TU_ID_DE_FORMSPREE` en `index.html` por el ID de tu formulario. Los datos se descargan en CSV desde el panel de Formspree.
